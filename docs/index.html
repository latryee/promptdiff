AST Structural Output Differ

Line-by-line diffs fail on structured JSON and JavaScript because whitespace or re-ordered keys generate false red alarms. PromptDiff parses outputs into abstract syntax trees to detect real schema breaking changes.

AST 1 (Baseline)
{
  "type": "Program",
  "body": [
    {
      "type": "Function",
      "id": "fetchData"
    }
  ]
}
AST 2 (Candidate)
{
  "type": "Program",
  "body": [
    {
      "type": "Function",
      "id": "fetchData"
    },
    {
      "type": "Class",
      "id": "UserService"
    }
  ]
}

Command Line Interface (CLI)

Run regression diffs, auto-prompt optimization, and token profiling directly from your terminal.

# Test two prompt versions against dataset promptdiff test prompt_v1.txt prompt_v2.txt --inputs data.jsonl --export-html report.html
# Compress prompt while maintaining quality promptdiff shrink verbose_prompt.txt --ratio 0.40
# Run MCTS auto-prompt optimizer promptdiff optimize baseline.txt --dataset testcases.jsonl
